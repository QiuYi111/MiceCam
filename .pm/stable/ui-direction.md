# UI Direction

**Approved direction**: Apple HIG system-level aesthetic — clean, minimal, SF fonts, SF Symbols, navy blue accent (`#1B2A4A`).

**Reference**: `specs/001-micecam-v2-rewrite/ui-spec.md` — complete design spec with color tokens, typography, layout metrics, component hierarchy, interaction patterns, animation tokens, and component tree.

**Approved by**: Grill session Q&A. User described "Apple style, clean, elegant, refined" and confirmed system-level HIG approach.

**Key decisions**:
- Light mode only (no dark mode for v2)
- Adaptive camera grid (not fixed 4+1)
- Global recording control (no per-camera toggles)
- Sidebar + grid + toolbar + status bar layout
- Alert banners: slide-in from top, color-coded
- SF fonts with fallback: Segoe UI (Windows), Noto Sans (Linux)
